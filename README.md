# AI Insights Evidence Visuals

This repo contains three interactive HTML prototypes for student-facing AI Insights evidence.

## Pages

- `index.html` — landing page
- `area-opportunity.html` — Area Opportunity
- `time-return.html` — Time Return
- `topic-recurrence.html` — Topic Recurrence

## GitHub Pages setup

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
5. Save.
6. Open the published GitHub Pages URL.
