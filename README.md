# AI Insights Evidence Visuals

This repo contains interactive HTML prototypes for student-facing AI Insights evidence.

## Pages

- `index.html` — landing page
- `integrated-drilldown.html` — Integrated Section → Area → Topic drilldown
- `area-opportunity.html` — Area Opportunity
- `time-return.html` — Time Return
- `topic-recurrence.html` — Topic Recurrence

## GitHub Pages setup

1. Upload all files to the repository root.
2. Go to **Settings → Pages**.
3. Choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/root**
4. Save.
5. Open the published GitHub Pages URL.
